# OpenCloud on Linux

Instalación y ejecución real de OpenCloud en Linux.

## Qué hace

Permite instalar y ejecutar OpenCloud en Linux sin depender de doble clic o interfaz gráfica.

## Requisitos

- Linux
- Terminal
- Permisos de ejecución

## Instalación

chmod +x install.sh start.sh stop.sh check.sh
./install.sh

## Ejecutar

./start.sh

## Verificar

./check.sh

## Detener

./stop.sh
